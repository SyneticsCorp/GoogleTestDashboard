# 합성 GoogleTest 결과 - 자동차 차일드락 예제

이 디렉터리의 모든 결과는 Jenkins와 GoogleTest 결과 수집 실습을 위해 생성한 **가상 데이터**입니다. 실제 차량, ECU, 안전등급, 인증 또는 시험 결과를 나타내지 않습니다.

## 구성

- Jenkins 빌드: 10회 (`01`~`10`)
- 빌드별 XML: 10개 (모듈별 1개)
- 빌드별 테스트: 1,200개
- 전체 XML: 100개
- 전체 테스트 실행 레코드: 12,000개
- GoogleTest XML 구조: `testsuites > testsuite > testcase > failure`
